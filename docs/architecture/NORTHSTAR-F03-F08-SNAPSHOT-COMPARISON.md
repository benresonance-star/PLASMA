## Differences worth preserving

- **Site versus illustration:** The concept includes photorealistic riverfront aerials and reality overlays. The QA screenshot uses an overtly labelled synthetic SVG site study. **No registration or capture authority is claimed.**
- **Geometry authority:** The concept shows photo-real hotel geometry. The implementation intentionally distinguishes persistent semantic identity from disposable exact-adapter meshes.
- **Evidence:** The concept's green badges and performance percentages are fictional. This version displays unverified or blocked gates instead of turning a visual into a certification.
- **Worldline:** The concept depicts a unified lifespan from site to operation. The current implementation only has session events and head hash, which are not an issued revision archive.
- **UI layout:** Both share Place / Design / Reason panels and a lower Worldline. The implementation is visually more restrained and currently less spatially rich.
