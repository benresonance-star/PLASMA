# Plasma engineering protocol

Before substantive work read [spec/README.md](spec/README.md), [North Star](spec/NORTH_STAR.md), the canonical constitution and relevant contracts on the current target revision. Record the spec commit SHA and requirement IDs in every engineering report. If unavailable, disclose and do not claim conformance.

Plasma is one coherent computational world. Studios are contextual working environments, not independent model authorities. Shared foundation supplies world state, computation and representations; human and agent intentions return through governed transactions. CAD-quality precision and game-engine-quality interaction are joint goals.

Inspect actual code and evidence before claiming completion. Use the existing spec graph and its status axes. Run pnpm spec:build, pnpm spec:check and relevant tests when possible; report exact results and limitations. Do not substitute synthetic fixtures for integrated or hardware qualification. For source archives record baseline commit or archive hash, spec revision, changes and tests; do not assume a ZIP equals GitHub main.

Follow spec/NORTH_STAR.md amendment procedure. Never weaken an invariant to accommodate a shortcut. Constitutional changes require explicit owner approval. Do not silently edit generated projections. Prefer a reviewable branch/PR for spec changes. Carry these instructions into downstream source distributions.
